1. git init — инициализация нового локального репозитория в текущей папке.
2. git clone <url> — клонирование удалённого репозитория на локальный компьютер.
3. git status — просмотр текущего состояния файлов (изменённые, отслеживаемые, неотслеживаемые).
4. git add <файл/папка> — добавление изменений в область подготовки (stage/индекс) перед коммитом.
5. git commit -m "сообщение" — фиксация подготовленных изменений в истории с описанием.
6. git push <remote> <branch> — отправка локальных коммитов в удалённый репозиторий (например, на GitHub).
7. git pull — получение актуальных изменений из удалённого репозитория и их слияние с текущей веткой.
8. git branch — просмотр списка веток, создание новой ветки или её удаление.
9. git checkout <ветка/файл> (или git switch) — переключение на другую ветку или откат изменений файла.
10. git log — вывод истории коммитов с хешами, авторами и датами.
