Основы Git

 1.Что такое Git и для чего он используется?
Git — это инструмент контроля версий, который фиксирует историю изменений в файлах проекта. Он позволяет сохранять состояния кода по шагам, безопасно экспериментировать в отдельных ветках, сравнивать версии и возвращаться к рабочему состоянию, если что-то сломалось. Также Git служит стандартом для командной разработки.

2.В чём разница между централизованными и распределёнными системами контроля версий?
В централизованных системах (например, SVN) есть один общий сервер, где хранится вся история; без подключения к нему нельзя сделать коммит или посмотреть старые версии. В распределённых (как Git) каждый разработчик скачивает полную локальную копию всей истории репозитория. Это позволяет коммитить, создавать ветки и смотреть логи полностью офлайн, а синхронизация с сервером происходит отдельной операцией.

3.Что такое репозиторий в Git?
Репозиторий — это рабочая папка проекта вместе со скрытой директорией .git, в которой хранятся база данных снимков состояния (коммитов), ссылки на ветки, настройки и полная история изменений проекта.
